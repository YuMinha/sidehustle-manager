# 부업 관리 프로그램

네이버 브랜드커넥트 부업의 키워드 → 글 → 성과 → 수익을 한 곳에서 관리하는 개인용 프로그램.

## 실행

```bash
git clone https://github.com/YuMinha/sidehustle-manager.git
cd sidehustle-manager
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열린다. 데이터는 `sidehustle.db`(SQLite 파일 하나)에 저장되고, 처음 실행하면 자동으로 만들어진다. 이 파일은 Git에 올라가지 않는다.

## 사용법

1. **키워드** — 판다랭크에서 본 키워드를 표 맨 아래 빈 줄에 입력하고 `저장`. 경쟁률은 비워 두면 자동 계산된다.
2. **콘텐츠 캘린더** — 쓸 글을 추가한다. 키워드·채널·발행 예정일을 고르고, 진행에 따라 상태를 `기획 → 작성중 → 발행`으로 바꾼다.
3. **성과 입력** — 글을 고르고 날짜별 조회수·링크 클릭·수익을 한 줄씩 추가한다.
4. **대시보드** — 이번 달 수익과 이번 주 할 일, 돈이 되는 글·키워드를 확인한다.

모든 표는 칸을 눌러 바로 고치고, 행을 선택해 삭제할 수 있다. 바꾼 뒤에는 꼭 `저장`을 누른다.

## 화면

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 이번 달 수익·조회·클릭, 이번 주 할 일, 수익 상위 글 5개, 키워드별 수익, 월별 수익 차트 |
| 키워드 | 판다랭크 키워드 추가·수정·삭제, 경쟁률 낮은 순 정렬, 사용 여부 표시 (경쟁률 비우면 상품수 ÷ 검색량으로 자동 계산) |
| 콘텐츠 캘린더 | 글 추가·상태 변경(기획 → 작성중 → 발행), 채널·상태 필터. 발행으로 바꾸면 발행일 자동 기록 |
| 성과 입력 | 글을 골라 날짜별 조회수·클릭·수익 입력 |

## 데이터 설계

```
side_hustles 1 ─< keywords 1 ─< posts 1 ─< stats
```

스키마는 [schema.sql](schema.sql). 키워드를 지우면 글의 키워드만 비워지고(`ON DELETE SET NULL`), 글을 지우면 성과 기록도 같이 지워진다(`ON DELETE CASCADE`).

## 파일

- `app.py` — Streamlit 화면 4개
- `db.py` — SQLite 연결, 표 편집 결과 저장(추가·수정·삭제)
- `schema.sql` — 테이블·트리거
- `test_db.py` — `python test_db.py`로 저장 로직 확인
