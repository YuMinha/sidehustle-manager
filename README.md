# 부업 관리 프로그램

네이버 브랜드커넥트(쇼핑커넥트) 부업 자동화 비서. 주제 찾기·초안·숏폼 영상·성과 정리는 프로그램이 하고, 사람은 고르기·경험 채우기·발행만 한다.

```
매일 아침 collect.py ─ 키워드 갱신 ─ 뉴스 수집 ─ 오늘의 추천 10개
                                                    │ 고르기 (사람)
초안 작업실 ─ AI 초안·캡션·숏폼 대본 ─ 경험·사진 채우기 (사람) ─ 숏폼 영상 ─ 릴스 업로드
                                                    │ 블로그 발행 (사람)
성과 입력 ─ 수익 리포트 파일 · 인스타 조회수 ─ 대시보드 ─ 다음 추천 점수에 반영
```

## 실행

```bash
git clone https://github.com/YuMinha/sidehustle-manager.git
cd sidehustle-manager
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열린다. 데이터는 `sidehustle.db`(SQLite 파일 하나)에 저장되고, 처음 실행하면 자동으로 만들어진다. 이 파일은 Git에 올라가지 않는다.

### API 키 (선택)

키워드 검색량을 자동으로 가져오려면 [네이버 검색광고](https://searchad.naver.com) → `도구` → `API 사용 관리`에서 키를 받아 프로젝트 폴더의 `.env`에 넣는다. `.env`는 Git에 올라가지 않는다.

```
SEARCHAD_CUSTOMER_ID=
SEARCHAD_ACCESS_LICENSE=
SEARCHAD_SECRET_KEY=
```

성수기·상승세와 뉴스까지 쓰려면 [네이버 클라우드](https://www.ncloud.com) 콘솔 → `NAVER API HUB`에서 Application을 등록하고(검색어트렌드·쇼핑인사이트·뉴스) 키 2개를 더 넣는다.

```
NAVER_HUB_CLIENT_ID=
NAVER_HUB_CLIENT_SECRET=
```

API HUB Application에 **블로그 검색**도 추가하면 블로그 경쟁률(블로그 글 수 ÷ 월 검색량)이 추천 점수에 들어간다.

초안 자동 작성과 뉴스 키워드 추출은 [Claude API](https://console.anthropic.com) 키가 필요하다 (사용한 만큼 과금, 초안 1개에 몇십 원 수준).

```
ANTHROPIC_API_KEY=
```

인스타 릴스 업로드·성과는 비즈니스/크리에이터 계정과 Meta 개발자 앱의 토큰이 필요하다. 이 부분은 실제 계정으로 아직 시험하지 못했다.

```
IG_USER_ID=
IG_ACCESS_TOKEN=
```

`python naver.py 캠핑의자`로 키가 동작하는지 바로 확인할 수 있다.

### 매일 자동 수집

`python collect.py`를 실행하면 저장된 키워드의 검색량·경쟁정도·상승세·성수기를 갱신하고, 뉴스 제목을 모으고, 오늘의 추천을 새로 뽑는다. Windows 작업 스케줄러에 등록해 두면 매일 아침 자동으로 돈다.

## 사용법

- **오늘 할 일** (첫 화면) — 내가 직접 해야 하는 일만 모아 보여준다: 추천 고르기, 초안의 빈자리 채우기, 발행하기, 성과·수익 파일 올리기.
- **초안 작업실** — `AI로 초안 만들기`를 누르면 블로그 초안·인스타 캡션·숏폼 대본이 한 번에 나온다. 초안의 `[직접 채우기: ...]` 자리에 실제 경험과 사진을 채운다. 사진을 올리고 `숏폼 영상 만들기`를 누르면 AI 목소리·자막이 들어간 세로 영상이 만들어진다. 발행 체크리스트(광고 문구, 제휴 링크, 빈자리, 사진)를 다 채워야 `블로그에 발행했어요`가 눌린다. 빈자리가 남은 글은 DB 트리거가 발행을 막는다.

0. **오늘의 추천** — `추천 새로 받기`를 누르면 관심 분야의 연관 키워드 수백 개 중 팔리는 상품 키워드(광고가 5개 이상 붙는 키워드)만 골라, 검색량·경쟁·상승세·성수기로 점수를 매겨 10개를 추천한다. `쓸래요`에 체크하고 `고른 키워드로 글 만들기`를 누르면 키워드 등록과 콘텐츠 캘린더의 '기획' 글이 한 번에 만들어진다. 분야별 씨앗 키워드는 `recommend.py`의 `CATEGORY_SEEDS`에서 바꾼다.
1. **키워드** — `연관 키워드 찾기`에 씨앗 키워드를 넣으면 연관 키워드 100개의 월 검색량·경쟁정도가 나온다. 고를 키워드에 체크하고 `선택한 키워드 추가`. `키워드 새로고침`은 저장된 키워드의 검색량·경쟁·상승세(지난달 ÷ 최근 1년 평균)·성수기(최근 3년 중 검색이 몰리는 달)를 다시 가져온다. 판다랭크에서 본 키워드는 표 맨 아래 빈 줄에 직접 넣어도 된다.
2. **뉴스** — 품절 대란·신제품·여행 수요 같은 검색어로 모은 최근 7일 뉴스 제목. 팔 만한 상품이 보이면 키워드로 추가한다. 사고·재난 뉴스는 자동으로 빠진다.
3. **콘텐츠 캘린더** — 쓸 글을 추가한다. 키워드·채널·발행 예정일을 고르고, 진행에 따라 상태를 `기획 → 작성중 → 발행`으로 바꾼다.
4. **성과 입력** — 글을 고르고 날짜별 조회수·링크 클릭·수익을 한 줄씩 추가한다. 브랜드커넥트 수익 리포트(엑셀·CSV)를 올리면 열을 고르는 것만으로 내 글과 맞춰 한 번에 들어간다.
5. **대시보드** — 이번 달 수익과 이번 주 할 일, 돈이 되는 글·키워드를 확인한다.

모든 표는 칸을 눌러 바로 고치고, 행을 선택해 삭제할 수 있다. 바꾼 뒤에는 꼭 `저장`을 누른다.

## 화면

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 이번 달 수익·조회·클릭, 이번 주 할 일, 수익 상위 글 5개, 키워드별 수익, 월별 수익 차트 |
| 키워드 | 판다랭크 키워드 추가·수정·삭제, 경쟁률 낮은 순 정렬, 사용 여부 표시 (경쟁률 비우면 상품수 ÷ 검색량으로 자동 계산) |
| 콘텐츠 캘린더 | 글 추가·상태 변경(기획 → 작성중 → 발행), 채널·상태 필터. 발행으로 바꾸면 발행일 자동 기록 |
| 성과 입력 | 글을 골라 날짜별 조회수·클릭·수익 입력 |

## 데이터 설계

```
side_hustles 1 ─< keywords 1 ─< posts 1 ─< stats
```

스키마는 [schema.sql](schema.sql). 키워드를 지우면 글의 키워드만 비워지고(`ON DELETE SET NULL`), 글을 지우면 성과 기록도 같이 지워진다(`ON DELETE CASCADE`).

## 파일

- `app.py` — Streamlit 화면 8개
- `db.py` — SQLite 연결, 표 편집 결과 저장(추가·수정·삭제)
- `schema.sql` — 테이블·트리거
- `naver.py` — 네이버 검색광고 API(검색량·경쟁정도·연관 키워드), API HUB(검색어 트렌드·뉴스)
- `ai.py` — Claude API: 블로그 초안·캡션·숏폼 대본, 뉴스 제목에서 상품 키워드 추출
- `video.py` — 숏폼 영상 (edge-tts 목소리 + 자막 + 사진, moviepy). edge-tts는 공식 유료 API가 아니라 바뀔 수 있다
- `instagram.py` — 인스타 릴스 업로드·성과 (Instagram Graph API, 미검증)
- `recommend.py` — 오늘의 주제 추천 (후보 걸러내기, 점수 계산, 고른 추천을 글로 만들기)
- `collect.py` — 매일 자동 수집 (키워드 갱신, 성수기·상승세 계산, 뉴스 모으기)
- `test_db.py` — `python test_db.py`로 저장 로직 확인
